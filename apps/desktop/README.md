# TongMuTV Plus 桌面客户端（Windows）

Tauri 2 壳：窗口里装的是系统自带的 WebView2（Edge 内核），打开你填写的服务器地址。网站更新，客户端自动同步，无需重新安装。

- 首次启动填写服务器地址，之后自动连接。
- `Ctrl+Shift+S` 更换服务器地址，`F11` 全屏。
- 窗口最上面是自绘的细标题条（最小化、最大化 / 还原、关闭，空白处按住拖动、双击最大化），颜色跟着网站主题走；网站切主题时，标题条和页面是同一个圆形扩散。网页全屏（含视频全屏按钮）时标题条自动收起。
- 支持 Windows 10 / 11（x64、ARM64）。Windows 7 / 8 不支持，请用浏览器访问。
- 安装包未做代码签名，首次运行会出现 SmartScreen 提示：点「更多信息 → 仍要运行」。

## 打包

全部在 GitHub Actions 里完成，本机不用装 Rust：

Actions → **Build Windows Desktop** → Run workflow，完成后在页面底部下载 `.exe`。

## 窗口结构

一个无系统边框的窗口里放两块页面：上面是本地标题条（`ui/titlebar.html`），下面是页面区（填地址页或你的网站）。网站的布局、滚动、全屏都发生在页面区里，网站代码完全不知道标题条存在。

- 标题条能控制窗口；页面区只能向壳报告主题颜色和全屏状态，不能控制窗口。权限在 `src-tauri/capabilities/`，命令清单在 `src-tauri/build.rs`。
- 网站主题颜色读自网页上现有的 `--tm-bg` / `--tm-text` 和切主题时写在 `<html>` 上的圆心、半径；其他网站退回读页面实际背景色，换色时 250ms 渐变。
- 自绘窗口创建失败时自动退回系统标题栏窗口，保证客户端至少能用。

## 目录

| 路径                      | 说明                                           |
| ------------------------- | ---------------------------------------------- |
| `ui/index.html`           | 本地"填写服务器地址"页                         |
| `ui/titlebar.html`        | 自绘标题条（按钮、拖动、跟随主题的圆形扩散）   |
| `src-tauri/src/main.rs`   | 窗口创建、两块区域排版、4 个命令               |
| `src-tauri/src/inject.js` | 注入每个页面的脚本：快捷键、全屏、主题颜色上报 |
| `src-tauri/capabilities/` | 谁能调用哪些命令                               |
| `src-tauri/icons/`        | CI 里用 `public/icons` 自动生成，不提交        |
