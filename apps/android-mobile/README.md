# TongMuTV Plus 安卓手机客户端

基于 WebView 的客户端，打开你填写的服务器地址。页面随服务器更新；原生能力需要安装包含对应功能的 APK。

- 首次打开填写服务器地址；长按桌面图标选「更换服务器地址」，或连接失败时在弹窗里改。
- 最低声明 Android 6.0（API 23），旧设备还需要能运行本站的系统 WebView。原生冒烟覆盖 API23/24/34，不能据此保证所有旧内核或厂商系统。华为纯血鸿蒙请用浏览器访问。
- 已处理：视频横屏全屏并保持常亮、返回键网页内后退、上传头像选文件、刘海屏和 Android 15 边到边留边。
- 本开发分支支持系统媒体会话、通知控制及满足条件时的画中画；后台表现还受系统电池策略和媒体来源影响，系统结束整个应用后无法保证持续播放。

## 普通文件下载（开发中，尚未发布）

- HTTP/HTTPS 附件先由本地确认，再保存到系统下载目录；Android 9 及更早系统按需申请存储权限，拒绝则取消该次请求。
- 公开文件交系统下载管理器；带登录凭据的文件由原生前台下载任务处理，重定向到其他站点时不转发原站 Cookie。进度、取消及结果使用系统通知；通知未授权时仍可下载，并说明保存目录。
- 下载不重载当前页面或重新创建播放器。登录下载被系统强制结束后暂不自动断点续传；Blob 文件和系统阅读器接管仍待后续覆盖，不能称所有文件能力都已完成。

## 打包

Actions -> **Build Android Mobile APK** -> Run workflow。完成后：

- `tongmutvplus-android-mobile`：APK
- `smoke-android-api23` / `smoke-android-api24` / `smoke-android-api34`：模拟器冒烟测试截图和日志

配了 `ANDROID_MOBILE_KEYSTORE_*` 四个 secrets 就出 release 签名包（可覆盖安装更新），没配只出 debug 包。
