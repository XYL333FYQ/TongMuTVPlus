# TongMuTV Plus 界面设计规范 v1

## 0. 怎么用
- 本文件是界面的唯一依据。冲突时以本文件为准；没写的先问。
- `reference/` 里的 `.dc.html` 是画板源码（静态示意）。参考它的结构、间距、层级。
  里面的 `{{ }}`、`renderVals`、`sc-for` 是画板工具语法，不要照搬。
- 本文件只描述界面，不改变业务逻辑。

## 1. 产品与原则
- 两个平级功能：自己看、房间（同步观影）。入口并列，谁也不是谁的附属。
- 主色只有黑、白、灰。彩色只来自影片本身（海报、剧照）。唯一例外：报错红，只用于错误态。
- 质感目标：Apple TV。大画面、大圆角、磨砂材质、细腻光影、存在感强的动效。
- 布局：统一栅格，左右对称，所有元素对齐栅格。
- 内容优先：界面退后，海报和画面是主角。

## 2. Design tokens

### 2.1 颜色
复用现有 `--tm-*` 名称（定义在 `src/app/globals.css` 约 1210 行起）。★ 为新增。

| token | 深色（默认） | 浅色 |
|---|---|---|
| --tm-bg | #0A0A0A | #FFFFFF |
| --tm-surface | #141414 | #F5F5F5 |
| --tm-surface-raised | #1C1C1C | #ECECEC |
| --tm-line | #262626 | #E5E5E5 |
| --tm-text | #FAFAFA | #0A0A0A |
| --tm-muted | #A3A3A3 | #6B6B6B |
| --tm-accent | 等于 --tm-text | 等于 --tm-text |
| ★ --tm-accent-contrast | #0A0A0A | #FFFFFF |
| ★ --tm-glass | rgba(28,28,28,.70) | rgba(255,255,255,.70) |
| ★ --tm-glass-solid | #1A1A1A | #F4F4F4 |
| ★ --tm-spot | rgba(255,255,255,.08) | rgba(0,0,0,.04) |
| ★ --tm-hero-bg | #141414 | #0A0A0A |
| ★ --tm-danger | #D92D20 | #D92D20 |

- 不再有蓝色强调色。
- 主题三选一：深色 / 浅色 / 跟随系统，默认深色（next-themes：defaultTheme="dark"，enableSystem）。
- 切换主题不允许闪白。文字对比度 ≥ 4.5:1。

### 2.2 字体
- Noto Sans SC，只用 400 / 500 / 700。回退：-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif。
- 国内访问 Google Fonts 不稳，用 next/font/local 自托管。字体文件若缺失，先用回退栈并在汇报里说明。
- 字号：Hero 标题 76（平板 56、手机 34）｜页面标题 40｜区块标题 22–28｜正文 14｜辅助 12。**禁止小于 12px。**
- 字距：大标题 -0.035em，页面标题 -0.02em。数字一律 tabular-nums。

### 2.3 间距与圆角
- 间距按 8px：4 8 12 16 20 24 32 40 48 64 72。
- 圆角：按钮、输入 10｜海报 14｜卡片 12–16｜大面板、Hero 24｜胶囊 999。

### 2.4 材质与阴影
- glass：`background: var(--tm-glass); backdrop-filter: blur(24px) saturate(1.6); box-shadow: inset 0 1px 0 rgba(255,255,255,.08); border: 1px solid var(--tm-line)`
  - 用于：胶囊导航、手机底栏、折叠播放条、底部弹层。
  - `html[data-tm-no-blur='true']` 时：去掉 backdrop-filter，背景改 `--tm-glass-solid`。
  - 不得叠在 `<video>` 之上做模糊。
- 海报立体感：`box-shadow: inset 0 1px 0 rgba(255,255,255,.07), 0 18px 32px -14px rgba(0,0,0,.55)`
- Hero 投影：`0 40px 80px -32px rgba(0,0,0,.7)`
- 页面顶部聚光（仅此一处允许的大面积渐变）：`radial-gradient(ellipse 70% 38% at 50% 0%, var(--tm-spot), transparent)` 叠在 `--tm-bg` 上。

### 2.5 栅格与断点
- 容器：max-width 1440，居中。左右 padding：≥1200 为 48｜768–1199 为 32｜<768 为 16。
- 海报列数：≥1200 为 6｜768–1199 为 4｜<768 为 3。间距：行 32 / 列 20（手机 20 / 12）。
- 桌面「继续观看」「我的房间」各占 3 列，每张 16:9 卡片刚好 1 列宽，与下方海报列对齐。平板上下堆叠各占满宽；手机横向滚动。
- 导航：桌面、平板为顶部胶囊导航；手机为底部悬浮 5 项。

## 3. 动效

### 3.1 token
```
--tm-ease-out: cubic-bezier(.22, 1, .36, 1);
--tm-ease-in-out: cubic-bezier(.65, 0, .35, 1);
--tm-spring: cubic-bezier(.34, 1.56, .64, 1);   /* 小幅回弹，只用于徽标出现、开关 */
--tm-d-press: 120ms; --tm-d-hover: 200ms; --tm-d-panel: 320ms; --tm-d-page: 360ms; --tm-d-hero: 600ms;
```

### 3.2 总规则
- 只动 transform 和 opacity。clip-path、filter 仅限一次性过渡。不动 width/height/top/left（小窗播放器除外，见 13）。
- 所有动效：`html[data-tm-reduced-motion='true']` 或 `prefers-reduced-motion: reduce` 时，去掉位移、缩放、视差、自动轮播，只保留 ≤120ms 淡入淡出。
- 优先用已有依赖 framer-motion（layout、layoutId、useScroll、useTransform）。其余用 CSS。不新增动画库。
- `will-change` 只在动画进行时加。

### 3.3 必做清单
1. **点按反馈**：按钮、卡片 `:active` scale(.97)，120ms。
2. **海报聚焦**（仅 `(hover:hover) and (pointer:fine)` 与键盘聚焦）：scale(1.05)、上移 4px、阴影加深，200ms。再加 3D 倾斜：perspective(800px)，rotateX/Y 最大 ±6°，跟随指针；表面叠高光 `radial-gradient(circle at var(--mx) var(--my), rgba(255,255,255,.18), transparent 55%)`；离开时 320ms 回弹。触屏不启用。
3. **海报入场**：进入视口 opacity 0→1、translateY 16→0；同一行逐张错开 40ms；只播一次。
4. **图片加载**：先显示 `--tm-surface-raised` 占位；图到达后 opacity + blur(12px→0)，320ms。
5. **Hero 轮播**：切换交叉淡入 600ms；背景图缓慢放大 scale 1→1.06（12 秒，切换时重置）；文字按 meta→标题→简介→按钮逐行入场，间隔 60ms，每行 opacity + translateY(12px)；向下滚动时背景以 0.3 倍速移动，文字渐隐并略缩小；自动轮播 8 秒，悬停暂停，减少动态时关闭。
6. **氛围背景（Ambient）**：Hero 与影片详情页背后铺当前海报/剧照的放大模糊图：`scale(1.4) blur(80px) saturate(1.3) opacity(.35)`，切换时 600ms 交叉淡入。这是界面里唯一的"彩色"，来自影片。
7. **胶囊导航**：选中块用 framer-motion `layoutId` 滑到新位置（320ms）；页面滚过 8px 后，顶栏出现玻璃底（200ms）。
8. **手机大标题**：页面标题 34px；下滚超过 40px 缩成 17px 居中，并出现玻璃顶栏。
9. **页面切换**：内容 opacity 0→1、translateY 8→0，360ms。播放器所在层不参与。
10. **海报→详情**：View Transitions API 共享海报元素（view-transition-name）。不支持则直接跳转。TypeScript 4.9 无 `startViewTransition` 类型，用类型声明补充，不要 `any` 扩散。
11. **主题切换**：以切换按钮为圆心做圆形扩散（View Transitions + clip-path circle，500ms）。不支持则 250ms 淡入淡出。
12. **手机底部弹层**：从底部弹簧滑入，可下拉关闭，背景压暗到 0.5，320ms。
13. **小窗播放器**：完整 / 小窗 / 折叠是同一个播放实例。形态切换时位置和尺寸做 FLIP 过渡（400ms ease-in-out），视频元素不得卸载重建。现有 `.tm-playback-host` 通过 `--tm-slot-*` 变量定位：只在该元素上加 transition，不改会话逻辑。
14. **放映模式（一起看）**：开始播放并保持 3 秒后，其余界面淡到 25%，背景渐变到 #000，600ms；鼠标移动或键盘操作恢复。减少动态时不启用。
15. **房间**：成员加入、离开头像缩放入场（spring，320ms）；新消息徽标弹跳 1 次；片单换位用 layout 动画；主持变更提示 4 秒后自动消失，不常驻。
16. **骨架屏**：`--tm-surface-raised` 加 1.6 秒缓慢扫光（白 6%），代替转圈。加载 <400ms 不显示。
17. **分段、标签、开关**：选中块滑动（layoutId），200ms。

### 3.4 禁止
过度弹跳、霓虹发光、旋转、彩色渐变、会引起晕动的大幅视差、动画期间阻塞操作、大面积 blur 做动画。

## 4. 组件规格
- **按钮**：主按钮（底 `--tm-text`、字 `--tm-accent-contrast`）｜次按钮（透明 + 1px `--tm-line`）｜玻璃按钮（Hero 上：`rgba(255,255,255,.14)` + blur(20px) + 1px `rgba(255,255,255,.3)`）。高 40 / 44 / 48，手机点按目标 ≥ 44。
- **评分角标**：全站只此一种。左上角，12px / 700，圆角 6，深色主题白底黑字、浅色主题黑底白字。不分档位、不画星星、不用彩色。替换 `VideoCard.tsx` 约 1320 行与 `globals.css` 中的 `.mtv-rate*`。
- **海报卡**：2:3，标题 14/500 左对齐。没有真实数据时不显示年份、类型。
- **继续观看卡**：16:9，底部 4px 进度条。
- **房间卡**：16:9 + 在线徽标（点：在线用 `--tm-text`，离线用 `--tm-muted`）+ 名称 + 状态行。同一行末尾固定一张虚线「创建房间」卡。
- **胶囊导航**：容器 glass；选中项实心 `--tm-text`；项为 发现 / 片库 / 房间；右侧为搜索图标、头像。
- **手机底栏**：发现 / 片库 / 房间 / 搜索 / 我的，悬浮 glass，标签 12px，选中项底色 `--tm-line`。
- **折叠播放条**：桌面底部居中 560 宽，手机左右各 16；高 56–64；内容：缩略图、标题 + 房间名、消息（未读数）、展开、关闭。
- **聚焦环**：`:focus-visible` 2px solid `--tm-text`，offset 2px。
- **复选、单选、开关**：自绘黑白，不用浏览器原生蓝色。
- **输入框聚焦**：2px `--tm-text` 描边，不再是绿色。

## 5. 页面规格

### 5.1 已设计（对应 `reference/`）
| 画板 | 文件 |
|---|---|
| 首页（桌面） | Main.dc.html |
| 首页（手机） | Phone.dc.html |
| 房间页（桌面） | Room.dc.html |
| 房间页（手机） | RoomPhone.dc.html |
| 规范速览 | Spec.dc.html |

**首页结构**：顶栏（三段对称）→ Hero（居中，「播放」「一起看」两个等宽按钮，左右箭头，圆点）→ 继续观看 | 我的房间（3+3）→ 分类大标题居中 → 海报 6×2 → 查看全部 → 全站折叠播放条。

**房间页结构**：标题区（名称、连接状态、成员头像、邀请、退出）→ 播放器 | 右侧面板。

**与画板的差异（以此处为准）**
- 桌面房间页右侧：上半「片单」，下半「聊天」常驻（带输入框），不藏在标签里。成员用头像簇，点开看列表。平板、手机才用 片单 / 聊天 / 成员 三标签。
- 手机底栏标签 12px，所有手机点按目标 ≥ 44px。
- 画板里 Hero 评分行的 ★ 不要；评分只出现在海报角标。
- 没有横版剧照（backdrop）的条目：不进 Hero 轮播，或用 contain 完整显示竖版海报，不得放大裁切。
- 「播放」是原有直接播放 / 查找片源逻辑；「一起看」是创建房间并带入影片。若现有接口不支持带片创建，只做跳转到房间页，并在汇报里说明缺口，不要改后端。

### 5.2 房间必须覆盖的状态（画板未画，按此实现）
已连接｜重连中（顶部细条）｜暂无主持｜房主交接中｜个人观看（播放器区显示「你正在个人观看」+「回到一起看」）｜另一标签页正在出声（「在这里听」）｜视频加载失败（「重新加载影片」）｜片单为空。
文案简短直白，不写口号。

### 5.3 尚未设计的页面（只套皮，不重排）
片库（douban）、搜索、影片详情、播放页、房间列表、创建 / 邀请弹窗、我的、登录注册、直播、音乐、漫画、书、短剧、私人影库、求片、下载、AI 推荐、屏幕共享、电视端。
- 只做：换 token、套统一外壳、清理杂色和渐变、文案按第 6 节。
- 片库网格行距从 `sm:gap-y-20` 改成统一 `PosterGrid`。
- 不改布局结构，等设计稿到位再改。后台 `admin` 完全不动。

## 7. 已知问题（改的时候顺手处理）
- 创建房间弹窗的密码框被浏览器自动填成登录密码：密码框 `autoComplete='new-password'`，房间名 `autoComplete='off'`（`RoomWorkspace.tsx` 约 816、882 行）。
- 房间提示（"房间主持已更新"）不会自动消失，且自己建房间也会弹：在 `ChatFloatingWindow.tsx` 展示层加 4 秒自动隐藏，并跳过自己触发的主持变更。不要改 `useWatchRoom.ts`。
- 搜索框聚焦描边是绿色：改 token。
- 顶栏搜索框、「探索」、侧栏搜索、侧栏底部罗盘功能重复：合并。原「探索」里的入口一个都不能丢，移到头像菜单的「更多」。

## 9. 修订

### 2026-10-11 — P3 首页展示修订

- Hero 图片方向以 HomeHero 中图片 onLoad 取得的 `naturalHeight > naturalWidth` 为准，不能仅依据 `backdrop_path`。豆瓣兜底可能把竖版海报放入该字段；不因此修改 API。
- 竖版 Hero：宽度 ≥768px 时左右各占一半，左侧文字左对齐、垂直居中；右侧海报卡居中，高 400px、比例 2:3、圆角 16px、带阴影，完整显示图片。背景铺当前影片的氛围模糊图。
- 宽度 <768px 时竖版海报卡居中、高 200px，下面放标题和两个等宽按钮，隐藏简介；Hero 高度自适应，最小 380px。
- 横版 Hero 保持居中叠字布局。仅横版使用底部压暗遮罩：`linear-gradient(to top, rgba(0,0,0,.72), rgba(0,0,0,0) 60%)`，叠加整体 `rgba(0,0,0,.2)` 压暗，替代原整幅 0.58 压暗。此遮罩加入渐变白名单，代码颜色仍通过 `--tm-*` token 使用。
- 浅色主题 Hero 投影为 `0 24px 48px -24px rgba(0,0,0,.2)`，Hero 氛围背景透明度最大 0.12；深色保持原值。
- 创建房间卡按正常网格顺序紧跟最后一间房，不固定第 3 列。
- 继续观看没有记录时隐藏整个区块，我的房间占满容器宽度；访客同样按没有观看记录处理。
- 手机 Hero 左右箭头垂直居中；深色首页区块标题使用 `--tm-text`，不能被旧灰色类覆盖。
- FireworksCanvas 保持本次修订前的状态：不恢复首页挂载，不修改组件。动效、减少动态与无模糊偏好仍遵守第 3 节。
