## 2026-10-30 客户端更新提醒（用户确认）

- 判断方式：客户端用「构建时间」（yyyyMMddHHmm，UTC，流水线出包时自动盖）判断新旧，不用用户的版本号；版本号与更新内容只在后台写一次，弹窗直接引用后台最新一条（后台没写就显示通用文案）。
- 弹窗（仅安卓手机壳和 Windows 壳里出现，普通浏览器与电视壳不出现）：打开 4 秒后、切回前台时检查（间隔 10 分钟）；标题"发现新版本 vX"，按钮"稍后 / 立即更新"；点"稍后"后同一个新版本 3 天内不再弹；有其他弹窗时顺延。旧版客户端（没有构建时间）按落后处理，同样会收到提示。
- 立即更新：新版安卓壳下载安装包并调起系统安装界面（仍需用户点安装、首次允许安装未知来源）；旧安卓壳和 Windows 壳打开下载链接，手动安装。
- "关于"页在客户端里显示"客户端构建于 …"和"检查更新"按钮。
- 服务器新增只读接口 `/api/client-update?platform=android|windows`（经用户放行，只新增一个文件，不改现有接口）：读发布页的 client-<平台>.json，缓存 10 分钟，下载文件名由本站写死。
- 流水线：推送到 main 且改动了对应客户端目录（apps/android-mobile、apps/android-tv、apps/desktop）时自动构建并跑冒烟；发布一步放在需要人工批准的 `release` 环境里，批准后才把安装包和版本清单换到"客户端下载"页。手动触发保留，`publish` 勾选决定是否进入发布。

## 2026-10-29 手机端 App 体验改造（用户授权，超出"只换皮"范围）

- 授权范围：手机端（安卓客户端壳 + 手机宽度网页）增加手势、转场方向和与壳的小接口；禁区文件（播放同步、房间、API、中间件等）与桌面布局不动。新代码放新文件，旧页面最多加一两行引用，且都有启用条件（仅壳内 / 仅手机触屏 / 不在"减少动态"下）。
- §4 手机底栏：增加滑块；按住横向拖动超过 10px 进入拖动，滑块跟手（transform，拖动时 scale 1.08），经过的项高亮并轻振，松手跳转，普通点按不变；拖回原项松手不跳转。减少动态时无滑动与缩放。
- §3.3 第 9 条页面切换：手机宽度下，点链接进入的新页从右侧 28px 淡入，返回（popstate）从左侧 28px 淡入，360ms，只动 transform 与 opacity；减少动态时只淡入 120ms。播放器所在层仍不参与。
- 下拉刷新：仅手机触屏、仅 / /douban /search /my 四个浏览型页面；页面在顶部、没有弹层、没有视频在播时可用；下拉 64px 触发整页刷新。播放页、房间等有长连接的页面不启用。
- iPhone 在浏览器（非主屏幕）里打开时，4 秒后提示一次"添加到主屏幕"，点"知道了"后不再出现。
- 安卓壳对接：网页检测到 `window.TMShell` 后调用 `ready()`，壳让页面铺满屏幕并把状态栏/导航栏高度写入 `--tm-shell-top/bottom`，`html[data-tm-shell]` 下 `--tm-safe-top/bottom` 取这两个值；旧网站不调用 `ready()` 时壳保持原来的留边，网页在旧壳（没有 TMShell）里什么都不做。
- 手机点海报进详情：详情面板从被点的海报卡位置放大展开（360ms，只动 transform 与 opacity，起点取触发元素的位置）；减少动态、桌面抽屉、触发元素不在屏幕内时沿用原来的底部滑入。
- 安卓壳：旋转手机到横屏且正在播放时，尽量让视频进入全屏（浏览器若要求用户手势会拒绝，拒绝时保持原样）。
- 暂未做：长按浮起菜单与弹层多档（现有长按底部操作表和详情底部弹层已有下拉关闭，不再另做）、播放器小窗下滑折叠（要改 PlaybackSessionProvider，属禁区；小窗拖动与吸附本来就有）、更新通知与版本号方案（用户要求改完再议）。

## 2026-10-27 播放与房间连接（用户确认按计划执行）

- 页面位置、成员关系、观看模式、当前设备控制权与画面形态分别管理；普通导航不换片、不退房、不恢复同步。个人观看不被房间快照覆盖，只有明确「回到一起看」恢复最新共同活动。
- 所有选片入口保留影片引用和操作意图；添加待看只改变指定房间片单，成功来自服务器确认；一起看与主持切片是明确动作。异步操作绑定原房间、影片和代次，失效回包不导航、不覆盖新选择。
- 房间常驻添加待看入口，播放中和片单为空也可用；推荐保留选下一部能力；选片后有成功提示、继续选片与返回房间。
- 返回房间只导航，恢复一起看是房间中的明确动作。片单保留已播放标记，首个待看不包含已播项；普通成员仅能移除自己尚未播放的条目，房主/授权主持可整理全部；不自动跨影片续播。
- 聊天栏与播放器/网页全屏输入共用唯一持久消息流，新消息在画面实时展示一次，历史补齐不飘屏。外部历史弹幕独立；保留原聊天已读规则。
- 直播/音乐/共享/TV 统一活动权限、恢复和声音归属，浏览不自动替房间切活动，状态回声不生成新指令。原生视频全屏和系统画中画的网页层能力按设备另验。
- 本轮新增的状态文案（第 6 节口径，只说发生了什么与下一步）：个人观看「正在个人观看，房间和消息保留」+「恢复一起看」；音乐非活动「房间当前没有在一起听」；屏幕共享等待「等待主持开始共享屏幕」，不支持「当前浏览器不支持屏幕共享…」（只禁用开始，不退房）；刷新后遗留的共享显示「重新开始共享」；外部观影室服务「当前使用外部观影室服务，房间目录和长期房间恢复仅内置服务提供」；TV 退出共同播放失败「未能退出共同播放，请重试」。语音控件仅在站点配置 ENABLE_ROOM_VOICE 开启时出现。无新增颜色、字号或动效。
- 用户授权本轮必要会话、同步、播放器和房间服务行为修改；沿用 token、字号/点按与动效规则，不改无关功能、依赖、数据库路径和 Socket 事件名。计划见 ../superpowers/plans/2026-10-27-playback-room-connections.md。

## 3. 动效

### 3.1 token

```
--tm-ease-out: cubic-bezier(.22, 1, .36, 1);
--tm-ease-in-out: cubic-bezier(.65, 0, .35, 1);
--tm-spring: cubic-bezier(.34, 1.56, .64, 1);   /* 小幅回弹，只用于徽标出现、开关 */
--tm-d-press: 120ms; --tm-d-hover: 200ms; --tm-d-panel: 320ms; --tm-d-page: 360ms; --tm-d-hero: 600ms;
```

### 3.2 总规则

- 只动 transform 和 opacity。clip-path、filter 仅限一次性过渡。不动 width/height/top/left（小窗播放器除外，见 13）。
- 所有动效：`html[data-tm-reduced-motion='true']` 或 `prefers-reduced-motion: reduce` 时，去掉位移、缩放、视差、自动轮播，只保留 ≤120ms 淡入淡出。
- 优先用已有依赖 framer-motion（layout、layoutId、useScroll、useTransform）。其余用 CSS。不新增动画库。
- `will-change` 只在动画进行时加。

### 3.3 必做清单

1. **点按反馈**：按钮、卡片 `:active` scale(.97)，120ms。
2. **海报聚焦**（仅 `(hover:hover) and (pointer:fine)` 与键盘聚焦）：scale(1.05)、上移 4px、阴影加深，200ms。再加 3D 倾斜：perspective(800px)，rotateX/Y 最大 ±6°，跟随指针；表面叠高光 `radial-gradient(circle at var(--mx) var(--my), rgba(255,255,255,.18), transparent 55%)`；离开时 320ms 回弹。触屏不启用。
3. **海报入场**：进入视口 opacity 0→1、translateY 16→0；同一行逐张错开 40ms；只播一次。
4. **图片加载**：先显示 `--tm-surface-raised` 占位；图到达后 opacity + blur(12px→0)，320ms。
5. **Hero 轮播**：切换交叉淡入 600ms；背景图缓慢放大 scale 1→1.06（12 秒，切换时重置）；文字按 meta→ 标题 → 简介 → 按钮逐行入场，间隔 60ms，每行 opacity + translateY(12px)；向下滚动时背景以 0.3 倍速移动，文字渐隐并略缩小；自动轮播 8 秒，悬停暂停，减少动态时关闭。
6. **氛围背景（Ambient）**：Hero 与影片详情页背后铺当前海报/剧照的放大模糊图：`scale(1.4) blur(80px) saturate(1.3) opacity(.35)`，切换时 600ms 交叉淡入。这是界面里唯一的"彩色"，来自影片。
7. **胶囊导航**：选中块用 framer-motion `layoutId` 滑到新位置（320ms）；页面滚过 8px 后，顶栏出现玻璃底（200ms）。
8. **手机大标题**：页面标题 34px；下滚超过 40px 缩成 17px 居中，并出现玻璃顶栏。
9. **页面切换**：内容 opacity 0→1、translateY 8→0，360ms。播放器所在层不参与。
10. **海报 → 详情**：View Transitions API 共享海报元素（view-transition-name）。不支持则直接跳转。TypeScript 4.9 无 `startViewTransition` 类型，用类型声明补充，不要 `any` 扩散。
11. **主题切换**：以切换按钮为圆心做圆形扩散（View Transitions + clip-path circle，`--tm-d-theme` 520ms，缓动 `--tm-ease-theme`；日冕环、底层后退、图标变形同时长同缓动）。不支持则 250ms 淡入淡出。
12. **手机底部弹层**：从底部弹簧滑入，可下拉关闭，背景压暗到 0.5，320ms。
13. **小窗播放器**：完整 / 小窗 / 折叠是同一个播放实例。形态切换时位置和尺寸做 FLIP 过渡（400ms ease-in-out），视频元素不得卸载重建。现有 `.tm-playback-host` 通过 `--tm-slot-*` 变量定位：只在该元素上加 transition，不改会话逻辑。
14. **放映模式（一起看）**：开始播放并保持 3 秒后，其余界面淡到 25%，背景渐变到 #000，600ms；鼠标移动或键盘操作恢复。减少动态时不启用。
15. **房间**：成员加入、离开头像缩放入场（spring，320ms）；新消息徽标弹跳 1 次；片单换位用 layout 动画；主持变更提示 4 秒后自动消失，不常驻。
16. **骨架屏**：`--tm-surface-raised` 加 1.6 秒缓慢扫光（白 6%），代替转圈。加载 <400ms 不显示。
17. **分段、标签、开关**：选中块滑动（layoutId），200ms。

### 3.4 禁止

过度弹跳、霓虹发光、旋转、彩色渐变、会引起晕动的大幅视差、动画期间阻塞操作、大面积 blur 做动画。
