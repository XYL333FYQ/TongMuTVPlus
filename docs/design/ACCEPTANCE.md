# 分端验收标准（2026-11-18 用户确认）

每一步改完按这里逐条打勾，汇报写清：过了的、没过的、没验证的（以及为什么没验证）。
设备档位定义见 `src/lib/device-tier.ts`（phone / phone-landscape / tablet / wide），
端（网页 / 电脑客户端 / App）见 `src/lib/platform.ts`（`html[data-tm-platform]`）。

## 所有设备

- [ ] 按钮不被画面、顶栏、底栏、窗口按钮盖住（检查“真正画在最上面的元素”，不能只看点击命中——画面设了点击穿透时命中会骗人）
- [ ] 任何状态都有退出路径：关闭、退出全屏、返回，且在屏幕内
- [ ] 点按区 ≥ 44px，字号 ≥ 12px，无横向滚动
- [ ] 深色、浅色各看一次；减少动态、关闭模糊时不出错
- [ ] 换页面不暂停、不重建播放器；房间同步用两个账号验证

## 手机竖屏（phone，约 390×844）

- [ ] 站点：底部导航，手机顶栏
- [ ] 房间页占满整屏，聊天输入框在最下面且让开系统横条
- [ ] 小窗 212×119：平时只有画面 + 3px 进度线（房间有未读时右上白点）；点一下出 3 个按钮（回去、关闭、播放暂停），3 秒自动收起；可拖动
- [ ] 面板从底部拉起
- [ ] 播放器：中间快退 / 播放 / 快进；底部时间、弹幕开关、全屏；右上设置。没有网页全屏、画中画、截图、音量
- [ ] iPhone 点全屏直接用系统全屏

## 手机横屏（phone-landscape，约 844×390）

- [ ] 站点：不显示电脑顶栏；内容让开刘海
- [ ] 房间页左右两栏（画面 / 聊天），不显示站点顶栏
- [ ] 全屏：左右让开刘海和圆角，底部让开横条；锁在左边中间，快退快进挨着播放键，互不重叠
- [ ] 退出全屏在左上和右下各一个；“发条弹幕”最宽 220，放不下缩成图标，不把按钮挤出屏幕
- [ ] 小窗同手机竖屏

## 平板（触屏，横竖都是；排版 data-layout='tablet'，2026-11-18 方案 A）

- [ ] 房间页没有站点顶栏；房间栏 → 画面 → 正在放映 → 大号选集（48 高）→ 今晚看什么
- [ ] 侧栏四个标签：聊天 / 片单 / 成员 / 活动；切走再回来，聊天输入到一半的字还在
- [ ] 横屏左右两栏（侧栏约 400 宽、到底）；竖屏上下排，侧栏占剩下的高度
- [ ] 键盘弹出：画面缩小不停播，输入框在键盘上面

## 平板竖屏（tablet，约 820×1180）

- [ ] 房间页见上面“平板”；其他面板从右侧滑出
- [ ] 小窗 320×180，交互同手机：点一下出按钮（完整一套），自动收起
- [ ] 播放器同手机竖屏的按钮集合

## 平板横屏（wide + 触屏，约 1180×820，矮屏约 845×553）

- [ ] 房间用平板排版（见上面“平板”），不照搬电脑
- [ ] 聊天栏不超出屏幕高度
- [ ] 小窗 320×180，点一下出完整按钮，自动收起
- [ ] 控制栏点一下出现，画面正中快退 / 播放 / 快进；没有网页全屏、画中画、音量
- [ ] 点聊天输入框能调出键盘，键盘弹出时排版不变（平板竖屏同样检查）
- [ ] 控制条两个弹幕开关：“弹”管弹幕源，对话气泡管房间弹幕，互不影响

## 电脑浏览器（wide + 鼠标，≥ 1280）

- [ ] 小窗、控制栏鼠标移上去出现，移开 / 3 秒收起；键盘聚焦也能出现
- [ ] 保留网页全屏、画中画；截图在“设置”里

## Windows 客户端（data-tm-platform='desktop'，最小窗口 800×500）

- [ ] 右上 138×32 留给窗口按钮：抽屉、对话框、详情页、播放页面板等所有贴顶边的关闭 / 操作按钮都让开（用 `--tm-window-controls-w/-h`）
- [ ] 没有网页全屏、画中画
- [ ] 800×500 也是电脑排版，不出现手机布局

## 验证手段

- 自动：`pnpm typecheck / lint / test / format:check`，房间相关 `pnpm test:rooms`，`scripts/check-design.mjs`
- 浏览器：390×844、844×390、820×1180、1180×820、845×553、1280×800 六个尺寸；客户端用 `html[data-tm-platform='desktop']` 模拟
- 真机：手机（iPhone / 安卓）、平板、Windows 客户端由用户部署后各看一遍；汇报里列出需要真机确认的条目
