```
  player/                      新播放器核心：Artplayer + hls 的薄封装，暴露 PlayerHandle
  player/plugins/              从旧播放器拆出的功能，每个一个模块：
                               danmaku / skip-intro / anime4k / subtitles / quality /

  media/                       影片解析：详情、片源搜索与测速优选、选集、续播记录、收藏

  mini/                        新小窗：离开播放页继续播放，可拖动/收起/关闭，点回播放页
src/features/together/         一起看（照 SyncTV）
  client/                      房间连接与状态（框架无关的类 + React hook）
  sync/                        同步引擎（沿用已测规则：时钟校准、变速追赶、等缓冲、回声抵消）
  pages/                       房间大厅、房间页
  room/                        房间页组件：播放器区、聊天（含弹幕）、片单（含选集）、成员、设置
  activities/                  屏幕共享、一起听音乐、一起看直播（重写接入新房间）
server/together/               房间服务（沿用已测的权限/片单/等缓冲规则，数据表重建、旧表清空）
```

依赖方向：`together` 可以使用 `watch/player` 和 `watch/media`；`watch` 不认识房间。
房间页有自己的播放器实例，不再借用全站播放会话。

## 界面方向

- **播放页**：桌面端左侧大播放器、右侧选集/换源栏；下方影片信息、评论、推荐。手机端播放器在顶，标签切换信息/选集/评论。
- **房间大厅**：卡片网格（封面、正在放映、在线人数、公开/私密），顶部“创建房间 / 输入房间号加入”。
- **房间页**（SyncTV 经典布局）：顶部房间栏（名称、在线、邀请、设置）；左侧播放器 + 当前影片信息；
  右侧标签栏「聊天 | 片单 | 成员」；手机端播放器在顶、标签在下。弹幕叠在播放器上。
- **小窗**：右下角圆角卡片，悬停显示控制条，可拖动吸边、收起成胶囊。
