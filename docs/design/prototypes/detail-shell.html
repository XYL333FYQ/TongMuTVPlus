影片详情：换到公共弹窗层

“之后”第 2 项的设计稿。影片详情（DetailShell，影片卡片、首页大图、播放页都用）现在自己画遮罩、自己管焦点和返回键， 是第三阶段之后最大的一块“自己做的弹窗”。这里只定换到哪种款式、哪里看得出变化； 面板里面的内容（海报、标题、简介、选集、演员）排版不动。颜色全部来自 src/styles/tokens.css。

要你拍板的四件事

编号 问题 建议（默认值） 另一个选择 看得见的变化
D-1 详情用哪种款式？ 手机竖屏用 sheet（贴底、离顶 56、带拖动条、手指下拉关闭）；手机横屏、平板、电脑用默认 dialog（居中，最宽 1000，和现在一样） 新加第六种款式 detail（大面板），四档都由它管 几乎没有：位置和大小都和现在一样。下拉手势换成全站共用的那一个（只认手指，鼠标拖不动）
D-2 遮罩用哪种颜色？ 全站统一的 --tm-scrim，拉面板时遮罩不再跟着变淡 保留现在的 --tm-hero-bg 60%（浅色 40%）和下拉时变淡 深色下遮罩略深一点、浅色下略不同；下拉时背景不再渐渐变亮
D-3 详情里“看海报大图”用什么？ 直接用看图零件 ImageViewer（viewer 款式：画面黑底、关闭在右上 44×44、下拉关闭） 保留详情自己的大图面板（面板底色、居中） 大图从面板底色变成全屏黑底，和长按菜单里的“查看海报”一样
D-4 播放页右侧的详情侧栏怎么办？ 保持现状：它不是弹窗（页面和播放器照常能点），不进弹窗层；只把它从 DetailShell 拆成单独的侧栏零件，免得一个零件两种行为 也改成弹窗层的 drawer（打开时播放器不能点、页面锁住） 建议方案没有变化

不变的

  • 面板里面的内容和排版（detail.css 的内容部分）、按钮、选集、演员、更多菜单。
  • 手机上点海报进详情时“从海报位置放大展开”的进场（减弱动效时照旧不放大）。
  • 返回键 / Esc 关最上面一层、关掉后焦点回到点开它的卡片；弹窗里再打开更多菜单、确认框时叠在上面。
  • 路由、接口、存储键都不动。
