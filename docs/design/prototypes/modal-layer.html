五种款式在四种设备档位

款式 手机竖屏 phone 手机横屏 phone-landscape 平板 tablet 电脑 wide 以后用在哪（第三阶段）
dialog（默认） 居中，最宽 460，四周留 16px；内容多了在面板里滚，不超过屏幕高（减去安全区）。和现在一样 公告、版本说明、下载设置等普通弹窗
sheet 底部面板 贴底满宽，顶部两角圆，带拖动条，可下拉关闭；底部让开系统横条 贴底，最宽 560 居中，最高屏幕高减 32 变成居中面板，最宽 480（大屏上贴底面板太扁） 长按菜单、房间的片单 / 弹幕面板
drawer 侧边抽屉 改成从底部拉起（同 sheet），符合 ACCEPTANCE“面板从底部拉起” 从右侧滑出，满高，宽 400；顶边让开安全区和 Windows 窗口按钮 账号菜单里的设置、下载管理
confirm 确认框 居中，最宽 400；两个按钮等宽，确认在右；层级在提示之上（--tm-z-toast + 1），能盖住别的弹窗 askConfirm()、删除 / 退出确认
viewer 整屏查看 铺满，底色是画面黑（不随主题），关闭在右上 44×44、让开刘海和窗口按钮；触屏可下拉关闭 图片查看、海报大图

五种款式共用的行为

打开 原生 <dialog>.showModal()：焦点关进弹窗，盖住顶栏、底栏和小窗；关闭后焦点回到打开它的按钮
返回键 沿用 useBackLayer：手机返回键 / 浏览器后退只关最上面一层，不离开页面
Esc 关最上面一层；确认框按 Esc 等于“取消”；确认中（按钮转圈时）Esc、点外面都不关
点外面关闭 点遮罩关闭（dialog、sheet、drawer、confirm）；viewer 点画面以外的黑底关闭。登记表里“点外面关闭”这一行由弹窗层承担，不另做公共工具
滚动锁 打开时锁住页面滚动，按引用计数：两层弹窗叠着时，关上层不解锁，关到最后一层才恢复原来的 overflow 和滚动位置（src/lib/scroll-lock.ts）
进场 遮罩淡入 320ms；dialog / confirm 上移 8px + 0.98 → 1 放大；sheet 从底部滑入；drawer 从右侧滑入；viewer 0.96 → 1 放大。缓动 --tm-ease-out，只动 transform 和 opacity
退场 200ms 反向（原生 dialog 关闭时没有动画，这一阶段只做进场；退场留给第三阶段按需加）
减弱动效 html[data-tm-reduced-motion] 或系统减弱动效时，全部只淡入 120ms，没有位移和缩放
关闭模糊 遮罩本来就是纯色 --tm-scrim，不用模糊；关闭模糊时样子不变
点按目标 关闭按钮 44×44，底部按钮高 44，列表项高 48；所有可点元素有 :focus-visible 环
