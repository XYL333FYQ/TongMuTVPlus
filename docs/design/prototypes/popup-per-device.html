各端弹出方式

原则：“怎么关、焦点、Esc / 返回键、锁页面”全站只有一份（弹窗层 ModalLayer、浮层 Popover）；“从哪出来、长什么样”每端各一套， 由零件按设备档位（src/lib/device-tier.ts）自己选，调用的页面不再各写一份。 下面把每种弹出物在四档上怎么出现一格一格画出来，切“现在 / 建议”对照。依据：docs/design/ACCEPTANCE.md （手机“面板从底部拉起”、平板“其他面板从右侧滑出”）。Windows 客户端同电脑，贴顶的按钮让开右上窗口按钮。

要你拍板的四件事

编号 问题 建议（默认值） 另一个选择
P-1 普通弹窗（个人中心、通知设置、改密码、电视访问、播放记录、收藏、版本信息……）现在四档都居中 手机两档从底部拉起；平板从右侧滑出；电脑居中不变 只改手机两档，平板仍居中

P-3 影片详情在平板上是居中大面板，和验收标准“平板其他面板从右侧滑出”冲突 保持居中（详情是看内容的，400 宽的侧栏放不下海报、简介、选集），验收标准改成“工具面板从右侧滑出，影片详情居中” 平板也从右侧滑出，宽 400，排版照播放页侧栏
P-4 手机横屏只有约 390 高，从底部拉起的面板最高约 358 和手机竖屏一样从底部拉起（最宽 560、居中贴底），内容在面板里滚动——和房间面板已定的做法一致 手机横屏改成从右侧滑出（满高、宽 400）

对照

不变的

  • 每种弹出物里面的内容和排版不动，只改“从哪出来、多大”。
  • 关闭方式：点遮罩（按下和松开都在遮罩上）、Esc / 返回键只关最上一层、底部面板手指下拉关闭；关掉后焦点回到打开它的按钮。
  • 确认框四档都居中（最宽 400）；看图四档都是整屏黑底；原集名提示四档都贴着集数按钮、不接收点按。
  • 播放页右侧不挡页面的侧栏（详情、AI 助手、纠错）只在大屏出现，行为不变；手机上打开的是对应的弹窗。
  • 接口、路由、存储键都不动。

改了以后代码怎么放

  • ModalLayer 新增一种款式 panel：手机两档 = 底部面板，平板 = 右侧抽屉，电脑 = 居中（P-1）。普通弹窗的调用方只把 variant 换成 panel，不写设备判断。
  • Popover 在手机两档自己改用弹窗层的底部面板款式（P-2），调用方不变；Select 同理。
  • 每个零件的“四档怎么出现”写成一张表放在零件旁边的注释里，验收时按表逐格对。
