# 影片详情规范（P7）

参考画板：`reference/Detail.dc.html`（桌面）、`reference/DetailPhone.dc.html`（手机）、`reference/ChooseRoom.dc.html`（一起看：选房间）。
画板语法（`{{ }}`、`renderVals`、`sc-for`）是工具语法，只参考结构、尺寸、层级。颜色一律用 `--tm-*`，动效遵守 DESIGN.md 第 3 节。

## 1. 形态

- 宽度 ≥ 768：居中弹窗。宽 1000（视口不够时为视口宽 - 48），高度不超过视口 - 80，超出时内部滚动。圆角 28，背景 `--tm-surface`，1px `--tm-line`，阴影 `0 40px 100px rgba(0,0,0,.55)`。遮罩深色 `rgba(0,0,0,.6)`，浅色 `rgba(0,0,0,.4)`。
- 宽度 < 768：底部弹层。顶部留 56px，圆角 `28 28 0 0`，顶部拖动条 36×5。可下拉关闭。
- 现有抽屉、居中两种模式合并：桌面和平板用居中弹窗，手机用底部弹层。

## 2. 结构（自上而下）

1. **头图区**（桌面高 300，手机不设头图）：有横版剧照就用；没有就用海报放大模糊（和 PosterAmbient 同款）。右上角关闭按钮：44×44 圆形，玻璃材质。
2. **海报**：桌面 200×300，手机 112×168；圆角 14（手机 12）。桌面压住头图下沿 90px，带 4px 面板色描边；手机与标题并排。
3. **信息块**：
   - 元信息行：年份 · 片长 · 类型，14px（手机 12px），`--tm-muted`
   - 标题：40px / 700（手机 26px），字距 -0.02em
   - 原名：14px（手机 12px），`--tm-muted`
   - 评分：统一黑白角标 + "N 人评价"。不要金色星标。
4. **动作行**：
   - 桌面：播放（168×48 主按钮）｜一起看（168×48 玻璃描边）｜收藏（48×48 图标按钮，`aria-label="收藏"`）
   - 手机：固定在弹层底部，玻璃底栏，padding `12 16 32`，三个按钮同高 48，播放和一起看各占一半。内容区底部留 96px，避免被遮挡。
   - "播放"和"一起看"同尺寸、同层级，主次靠实心与描边区分，不靠大小。
5. **选集**（仅剧集）：方块按钮 48×44，当前集实心。桌面换行，手机横向滚动。保留原有选季、选集逻辑和数据。
6. **下半区**：
   - 桌面两列 `2fr 1fr`，间距 48。左：简介、导演、演员。右：信息卡（类型、年份、片长、评分），圆角 16。
   - 手机单列：简介（3 行截断 + "展开"按钮，点按区高 44）→ 导演 / 演员。
7. **原有其他区块**（评论、相关推荐、预告片等）：不删除，放在以上内容之后，只套 token，不重排内部。这些区块的设计后续再补。

## 3. 一起看

点"一起看"，打开"选房间"面板：

- 桌面：详情弹窗内的次级弹层，宽 420，居中。手机：底部弹层（见 ChooseRoom.dc.html）。
- 内容：
  - 小标题"一起看"，下面是影片名
  - 说明文字"加入哪个房间的片单？"
  - 房间列表。每行：缩略 64×36、房间名、"N 人在线 · 状态"、"加入片单"按钮（高 44）
  - 底部"新建房间并加入片单"（虚线描边，高 52）
  - 底部小字"加入片单不会打断房间正在播放的影片"
- 房间列表复用首页 `HomeRooms` 用的 mine 房间接口。访客点"一起看"：引导登录，不显示面板。
- **能力核实（实现前必须先查并汇报，不要猜）：**
  1. 用户当前已连接某个房间时，`useWatchRoom` 里是否已有"加入片单"方法
  2. 用户未连接的房间，前端能不能直接加片单
  3. `createRoom` 是否支持带初始影片
  - 做不到的项不改后端。降级方案（可改进）：跳转房间页，并在 `sessionStorage` 存一个待加入影片；房间连接后，页面顶部出现横幅"把《X》加入片单？"，【加入】【忽略】；用户确认后，调用已有的加入片单方法。
  - 任何新增存储键都要在汇报里列出，等我确认再写。

## 4. 动效

- 桌面：遮罩淡入 200ms；面板 opacity 0→1 + scale .98→1，320ms，`--tm-ease-out`。
- 手机：弹层从底部弹簧滑入 320ms；下拉超过 120px 或速度够快就关闭；背景压暗随拖动变化。
- 头图氛围层 600ms 交叉淡入（`PosterAmbient` 已有）。
- 选房间面板用同样的进出动效。
- 减少动态：只保留 120ms 淡入淡出；下拉关闭手势保留，去掉联动动画。

## 5. 无障碍

- `role="dialog"`，`aria-modal="true"`，标题关联。初始焦点在关闭按钮。Esc 关闭。焦点锁在弹窗内。关闭后焦点回到触发它的海报。
- 所有点按目标 ≥ 44px，最小字号 12px，对比度 ≥ 4.5:1。

## 6. 验收

- 1280、820、390 三个宽度，深浅各一次；电影和剧集各一部；有横图和无横图各一部；访客态。
- 手机滚到底，固定底栏不遮挡最后一行内容。
- 选房间面板：有房间、无房间、未登录三种。
- 现有 `DetailPanel.actions.test` 继续通过。新增测试：选集显示和隐藏、选房间面板打开关闭、Esc 关闭、集数为 0 不渲染 "0"。
- 换页、收起小窗、恢复：播放器仍是同一个 video 节点。
- 汇报：改了哪些文件、对应本文哪一节、验证结果、没做的和风险。
