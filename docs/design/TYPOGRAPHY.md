# 排版与文案规范 v2

本文件优先于 DESIGN.md 的 §2.2（字体与字号）和 §6（文案规则）。冲突时以本文件为准。
参考画板：`reference/Type.dc.html`（`{{ }}`、`renderVals`、`sc-for` 是画板工具语法，只参考样式）。

## 1. 字体

- 主字体：**HarmonyOS Sans SC**（华为，免费商用）。字重只用 Regular 400、Medium 500、Bold 700，字体本身没有 600，不要写 600。
- 文件由用户放进 `public/fonts/`。用 `next/font/local` 接入，导出 `--tm-font-sans`。文件缺失时停下汇报，不要伪造路径。
- 回退栈：`'Noto Sans SC', -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`。
- 数字和英文也用这个字体，不要让数字落到另一种字体上（现在大图标题"潜伏 6"里的 6 就是另一种字体）。

## 2. 字号层级

| 角色     | 桌面 | 手机 | 字重 | 说明         |
| -------- | ---- | ---- | ---- | ------------ |
| 大图标题 | 56   | 34   | 700  | 行高 1.15    |
| 页面标题 | 32   | 28   | 700  |              |
| 区块标题 | 24   | 20   | 500  |              |
| 小标题   | 18   | 18   | 500  |              |
| 正文     | 16   | 16   | 400  | 行高 1.7     |
| 次要信息 | 14   | 14   | 400  | `--tm-muted` |
| 说明     | 13   | 13   | 400  | `--tm-muted` |
| 评分角标 | 12   | 12   | 500  | 只给角标     |

- **字距：所有中文一律 0。** 删掉全站负字距（`letter-spacing: -0.02em`、`-0.035em` 等）。纯英文大标题最多 -0.01em。
- 最小字号：桌面正文和次要信息 ≥ 14px，说明 ≥ 13px；12px 只给评分角标。DESIGN.md 里"最小 12px"作废。
- `--tm-muted` 在白底上必须 ≥ 4.5:1，不得比规范色更浅。

## 3. 对齐与层级

- 页面标题、区块标题一律左对齐。居中只用于：大图内容、空状态、弹窗标题。取消首页"分类大标题居中"。
- 区块标题行：左边标题（24/500），右边"查看全部"（14，`--tm-muted`，不带箭头字符）。
- 一页之内同一层级只用一种标签样式：
  - 一级分类（电影、剧集）：下划线标签，18/500，选中项加 2px 下划线。
  - 二级筛选（热门、最新、经典）：胶囊，14/500，选中项实心。
  - 现在首页（大号文字标签）、片库（下划线 + 胶囊混用）样式不一致，统一成上面两种。
- 间距：区块之间 64（手机 40）；标题到内容 16（手机 12）。
- 卡片宽度来自栅格，不随内容或可用宽度拉伸。

## 4. 卡片文字

- 海报下方：标题 14/500，最多 1 行，超出省略；说明 13，`--tm-muted`，内容是"年份 · 类型"。
- 没有真实数据就不显示说明。**不要在每张卡下面重复写"电影"**（片库的电影分类下每张都写"电影"，没有信息量）。
- 标题不要加粗到 700。

## 6. 验收

- 全站搜索 `letter-spacing` 为负的规则，应为 0 处（英文大标题除外）。
- 全站搜索 `font-size` 小于 13px 的规则，除评分角标外应为 0 处。
- 首页、片库、房间列表：标题都左对齐，同一层级只有一种标签样式。
- 截图：浅色 + 访客 + 1920 宽，深色 + 登录态 + 1280，手机 390。
