# 主题辨识度、文字边界与手机房间优化计划

**Goal:** 修复用户三张截图中的主题预览、用户表格和代理开关，并逐页检查文字溢出、优化手机房间视频比例。

**授权:** 用户在已提供文件、顺序和风险的计划后回复「开始」。允许 admin/page.tsx 中本任务相关的界面修改；不涉及后台行为、权限、接口、存储键、Socket 或播放会话逻辑。原阶段不提交、不推送、不部署，不增加依赖。用户在本地验收后明确要求「提交推送」，现授权本批提交并推送 main，不手动部署。

**实现:** 沿用 Next.js / React、--tm-\* tokens 及现有布局。由当前实现者顺序执行，不并发改项目。先验证视频尺寸监听，再改展示；CSS 问题以真实浏览器测量和截图为准。

## 顺序与文件

- [x] 主题：themes.ts、theme-presets.json、后台选项及独立预览组件；同时展示深浅配色，预设背景增加辨识度，正文/强调/错误色保持原合同。
- [x] 后台：admin/page.tsx 及作用于后台的样式；表格操作换行，长文字可读或明确省略并可查看，滚动限定在表格内部；代理开关视觉轨道约 40×22，点击区至少 44×44。

## 风险与验收重点

- 视频尚无 metadata、换片、分辨率变化、组件卸载和重挂载要回退及清理监听；不得重建 video。
- 框内跟随实际视频尺寸；视频文件内部编码的黑边不会自动裁掉。
- 长用户名、链接、房间名、多个管理操作和 320px 手机需核对，保留 44px 点击与 focus-visible。
- 七个主题在深浅两种模式都需能区分并保持文本对比；预览不写数据库。
- 动效响应站内与系统减少动态；不把隐藏溢出当修复。
