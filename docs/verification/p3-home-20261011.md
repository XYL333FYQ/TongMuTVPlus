## 浏览器行为验证

使用本机 Chrome、实际公开数据和本地 QA 账号。截图使用系统减少动态以稳定画面；普通动效另行验证。

- 390 / 820 / 1280，深浅两种主题，body.scrollWidth 均等于视口宽度。海报列数分别为 3 / 4 / 6，仅两行。网格间距手机 20px × 12px，其余 32px × 20px；旧横向行给第一张卡片加的底部 padding 已归零。
- Hero 手机两个按钮各 153 × 44px，桌面和平板各 148 × 48px；左右箭头、圆点目标为 44px。详情新按钮各 157 × 48px（390px 视口）。
- 实际触摸事件短按首页分类海报进入现有详情，地址仍是首页。继续观看卡短按进入原播放路径，不被新详情入口接管。
- Hero 播放仍进入 /search?q=影片名；一起看进入 /watch-room。没有自动创建、加入房间或写入片单。
- 本地 MP4 经真实播放器解码：readyState=4；切到首页并打开详情，视频节点保持相同，时间从 0 推进至约 114 秒、仍未暂停。进入搜索 / 房间、收起小窗后节点仍相同，folded 形态得到确认。此次证明单实例和个人播放连续性，不代表双客户端同步验收。
- 正常动效：手机 390px 普通模式会按 8 秒切换，系统减少动态模式保持不变；桌面悬停 8.5 秒标题不变，移出后 8.5 秒切换；海报实际 rotateX≈5.68°、rotateY≈−5.47°，符合 ±6°，聚焦 / 高光与阴影可见。
- 应用减少动态开启、系统无减少动态时：8.5 秒不自动切换，card transform=none。关闭模糊时 ambient filter=none、玻璃 backdrop-filter=none。系统减少动态也用于截图检查，图片仅淡入、无倾斜。
- 访客使用独立无登录浏览器上下文，竖版 Hero 图 object-fit=contain，详情播放链接保持原登录限制，一起看指向房间页。公开海报原站 418 后能使用已有回退域加载，未调用私有图片代理。

键盘聚焦已验证 2px 描边、scale(1.05) / 上移 4px，Enter 进入详情。尺寸、访客和动效记录见 browser-final.log、motion-normal.log、motion-mobile.log、keyboard.log；触屏详情截图见下表。

## 保守处理与未完成项

- 当前 createRoom 不支持初始影片参数。按任务许可，“一起看”只跳转房间页，未声称带片创建。房间卡和创建卡也跳转原房间页，未追加自动入房 / 建房逻辑。
- 房间列表没有影片封面，使用 Film 图标，人数、名称、休眠状态来自现有数据，不伪造封面。当前房间有播放状态时显示真实影片名。桌面创建卡固定第三格；未用虚构房间填补空格。
- 访客保持原 PublicFilmDetails 公开详情，而不挂载可能请求私有 API 的 DetailPanel。登录后首页触屏进入 DetailPanel；两个路径都补播放 / 一起看，原搜索入口保留。
- 即将上映没有现成的专用全部路由，其“查看全部”保守进入电影片库。当前本地 TMDB 配置导致 upcoming 请求 400，没有显示伪造的即将上映数据；该分类与预告视频分支未完整浏览器验收。
- 新 Hero 按画板使用固定高度（桌面 500、手机 340）；旧高度倍率存储仍保留，对新展示不生效。原音乐 / 漫画 / 书入口保留在 P2 头像“更多”；AI、源站寻片、直链打开保留在首页工具区。
- 本轮移除首页 FireworksCanvas 挂载，未删除组件或其他页面的现有功能。
- 统一评分不再使用旧锦旗 / 勋章设置值；设置界面与存储键暂留，后续仅清理对应展示选项。
- 未对所有旧详情、播放、片库、登录、用户菜单、下载等页面进行颜色清理。VideoCard 的非首页来源徽标 / 管理提示仍有旧彩色与小字号；DetailPanel 原资料区仍有彩色与旧尺寸；PublicCatalog CSS 中旧 tm-public-rating 样式已无渲染入口，后续清理。这些不属于 P3 的全页重排范围，留给 P5。P3 不能标记“全站无杂色 / 全站最小字号”通过。
- 未做 Safari / Firefox / 真机、触屏实机手势、双客户端同步观影、完整主题跟随系统再验收；本轮触屏验证为浏览器触摸事件。首屏防闪白 / 系统主题沿用 P1 的验证边界。
- Noto Sans SC 仍缺失，继续使用 P1 回退栈。需要提供包含中文的 Noto Sans SC 可变 WOFF2（覆盖 400–700）或相应静态字重文件及许可文件，再接 next/font/local。
- 本次没有 commit、push 或部署。下一步是 P4 房间与播放展示层，需按对应任务执行。
