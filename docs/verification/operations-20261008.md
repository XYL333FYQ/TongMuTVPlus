## 50 连接房间信令

命令：

```sh
node scripts/ops/room-load.cjs --connections 50 --duration-ms 30000 --output docs/verification/room-load-50-20261008.json
```

执行时间：2026-10-08T10:11:28.969Z 记录完成。真实 Socket.IO/WebSocket 客户端经过现有登录签名与账号令牌认证，连接独立 Node 子进程；服务使用生产的 room-store、room-service、room-auth、room-transport 模块。

每房每秒更新一次播放状态、每 10 轮加入一次片单；每个连接每 5 轮发送一条消息。ACK/快照/聊天统计包含连接建房阶段与负载阶段；CPU 和事件循环在负载阶段开始时重置。快照字节是应用 JSON 内容合计，不是网卡或加密后的实际流量。

这个结果证明本机短时间内可以承受上述房间控制消息，并未测量 Next 页面渲染、真实视频下载、音视频代理、浏览器解码、WebRTC 音视频载荷或容器。50 条消息连接不能换算成 50 路媒体吞吐；也不能代替低配置 VPS 和长时间运行验证。
