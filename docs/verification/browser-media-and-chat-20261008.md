# 内置浏览器：实际媒体、连续播放与聊天

时间：2026-10-08 14:52–15:04 UTC。全部为本机隔离测试库和原创媒体，未读取或更改正式账户数据。

## 环境与方法

- WSL Ubuntu/Node22 自定义服务器，127.0.0.1:3199；内置浏览器桌面 1280×720。
- 两个真实登录账号分别使用 localhost:3199 与 member.localhost:3200。Cookie 按主机隔离，端口本身不能隔离 Cookie。
- 3200 只做 loopback HTTP/WebSocket 反代。媒体服务 3201 只提供 Temp 白名单测试文件，支持 Range/CORS/MIME。
- FFmpeg 生成 120 秒 1280×720、H264/yuv420p、AAC48k 测试图案和轻音调；文件及生成日志均在系统 Temp。HLS 测试文件也已生成，但本报告不冒充已播放。
- 所有页面动作通过内置浏览器表单/按钮；媒体状态与节点由只读 DOM/CDP 查询。没有直接调用前端状态容器来伪造界面结果。

## 发现与修复状态

1. 聊天通知的底部空白 margin 导致整个透明容器挡住小窗进度条。DOM elementFromPoint 命中 tm-chat-layer 而不是进度控件，实际点击未 seek。已将父容器 pointer-events:none、真实子内容 auto；WSL 热更新未生效，不能宣称修复已实测通过。
2. 原 Socket 客户端只重试 5 次；超过窗口的服务重启后两端仍停重连，已确认需要修复。连接管理器正在补持续退避、明确取消与首次失败后的迟到连接处理。
3. 公开 Google 测试 MP4 取得 currentSrc 但 readyState=0、尺寸 0 并网络失败；换成同播放器的本地原创 MP4 后成功。外部源可用性仍须在可访问网络环境验收。
