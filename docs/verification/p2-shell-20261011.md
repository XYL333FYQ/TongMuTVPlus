浏览器：本机 Chrome，首页 390/820/1280 × 深色/浅色，六组无页面横向滚动。桌面胶囊中心位于 640px（1280 宽）及 410px（820 宽）。底栏标签 12px，实测点按区域至少 67×50px。容器工具实测 padding 16/32/48，海报列 3/4/6，行列间距符合规范，1600 宽时容器封顶 1440。这里验证的是工具组件，没有把首页内容改成新网格。

- 顶栏滚动超过 8px 后玻璃 opacity 为 1；手机超过 40px 后标题 scale(0.5)，34px 的视觉尺寸收缩为 17px，居中。分别等待动画结束后核对。
- 关闭模糊后 backdrop-filter 为 none；减少动态时标题用 17px 直接切换、页面只淡入；系统减少动态也读取。
- 页面入场使用 CSS opacity/translateY(8px)，360ms；胶囊 layoutId 使用 framer-motion，320ms。录制到了选中块中间位置；播放器、直播、音乐及嵌入层不参与内容入场。
- 本地 MP4 通过现有“打开直链”播放，从完整页回首页，小窗 → 折叠 → 房间页：video 元素相同，时间 0.09→2.58 秒，已解码帧 6→66。桌面另一次检验时间 13.79→15.02、帧 335→364。见 player-final-continuity.log、player-continuity.log。
