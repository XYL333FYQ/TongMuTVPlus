## 浏览器证据

Chromium，实际本地首页与数据；通过账号菜单切换主题。截图时开启操作系统减少动态，避免轮播及入场影响静态证据。触屏详情使用真实 TouchEvent 处理路径，由浏览器工具派发；没有做物理手机验收。

- 390 / 820 / 1280 深浅主题各一张，body 宽度分别为 390 / 820 / 1280，无横向溢出。
- 真实豆瓣海报自然尺寸为竖版，登录首页此前被 backdrop 标记误判的潜伏 6 现已进入竖版布局；桌面卡高 400px、宽约 267px，手机卡高 200px、宽约 133px，比例 2:3。
- 深色各区块标题实际颜色均为 rgb(250,250,250)，与 --tm-text 相同；浅色为 rgb(10,10,10)。截图与 computed style 已核对。
- 截图另发现 Hero 的模糊氛围层覆盖下方内容，让颜色值正确的标题仍视觉发灰；已将首页内容设为相对定位、层级 1，让氛围留在内容背后，重新截图核对。

- 空记录访客首页不出现继续观看；房间区与父容器宽度均为 1184px。登录空记录路径另有组件测试，不清空现有账号观看记录做截图。
